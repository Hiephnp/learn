# learn

Kho này chứa tài liệu học tập (chủ yếu là file phụ đề .srt) cho khóa "PMP Certification Complete" (nguồn/định dạng lưu trữ: O`REILLY). Nội dung được tổ chức theo bài học và chuyên đề, phù hợp để ôn luyện kiến thức PMP / PMBOK.

## Những gì có trong repo
- README.md (tệp mô tả này).
- Thư mục chính: `PMP Certification Complete_O\`REILLY_01/`  
  - Bên trong có các thư mục bài học theo thứ tự: `[1] Lesson 1_ Getting Prepared for the PMP® Exam`, `[2] Lesson 2_ Learning Foundational Concepts`, `[3] Lesson 3_ Project Integration Management`, ... tới các lesson liên quan đến Scope, Schedule, Cost, Resource, Risk, Stakeholder, v.v.
  - Mỗi bài học chứa nhiều file `.srt` (phụ đề/transcript) cho từng đoạn video/tiết học (ví dụ: `1.5 Learning the PMP® Exam Content.srt`, `4.4 ITTOs of Scope Management.srt`, `9.7 The RACI Chart.srt`, ...).

## Các chủ đề chính (ví dụ)
- Chuẩn bị cho kỳ thi PMP (loại câu hỏi, cách ôn)
- Khái niệm nền tảng về dự án
- Project Integration Management (bao gồm Manage Project Knowledge, Lessons Learned, ...)
- Project Scope Management (ITTOs, quản lý phạm vi)
- Project Schedule Management (lập lịch, ITTOs)
- Project Cost Management (cost baseline, quản lý chi phí)
- Project Resource Management (RACI, resource calendar, Kanban)
- Project Risk Management (ITTOs, SWOT, prompt lists)
- Project Stakeholder Management

## Cách sử dụng nhanh
- Nếu bạn có video gốc: ghép file `.srt` vào video để xem kèm phụ đề.
- Nếu chỉ dùng để đọc: mở các file `.srt` bằng trình soạn thảo văn bản để xem transcript/tóm tắt nội dung bài giảng.
- Tìm kiếm nội dung: dùng chức năng tìm trong IDE / editor (keywords như "ITTO", "RACI", "Kanban", "resource", "risk").

## Lưu ý về bản quyền
- T��i liệu trong repo dường như là phụ đề/transcript của khóa thương mại (O`REILLY). Hãy đảm bảo quyền sử dụng và phân phối hợp pháp trước khi chia sẻ, xuất bản hoặc dùng công khai.
- Nếu bạn không sở hữu quyền, repo chỉ nên dùng cho mục đích học tập cá nhân.

## Góp ý / Liên hệ
- Nếu bạn là chủ repo muốn sắp xếp / gắn nhãn hoặc thêm file tóm tắt cho từng lesson, hãy thêm issue hoặc PR.
- Đề xuất: thêm một index (ví dụ index.csv hoặc index.md) liệt kê tiêu đề bài học và đường dẫn tới file `.srt` để dễ tra cứu.
